Raspberry Pi setup

To set up the Raspberry Pi, we used the given materials:

  • Raspberry Pi Model 4B 1GB
  • Raspberry Pi Touch Display 2
  • Raspberry Pi 15W USB-C Power Supply
  • 32GB Micro-SD Card

Installation of dependencies

A couple of dependencies have to be installed in order for the Raspberry Pi to work as it’s supposed to be. The only dependency we needed at this time was Docker. I installed it using following commands:

curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

Configuration files

For the Docker container, I put the docker run command in the autostart file for the root user, since Docker has to run with sudo (superuser / administrator) permissions:

/root/.config/labwc/autostart

docker run -d --name php -p 8080:80 -v /tmp/station:/tmp/station -v /opt/station/www:/var/www/html php:8.4-apache

For the browser in kiosk mode, I put the following command in the autostart file for the user (moria904), to open the browser with the given URL in kiosk mode:

/home/moria904/.config/labwc/autostart

chromium http://localhost:8080 --kiosk --noerrdialogs --disable-infobars --no-first-run --enable-features=OverlayScrollbar --start-maximized --force-device-scale-factor=1.75

I also adjusted the default scaling to 175% by adding the --force-device-scale-factor=1.75 argument so the text is readable instead of having to zoom in before being able to read it.

When the docker container is running and the autostart file for the user is adjusted, the website will open as soon as the Raspberry Pi is booted.
